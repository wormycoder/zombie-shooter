## Debug mode

Switch it on in Settings > Experimental > Debug mode, or open the game with `?debug` in the address. F2 or the `` ` `` key then shows or hides the debug window: cheats, spawners, time, weather, utilities, teleport (Ctrl+click), player stats and world overlays. In a debug session the What's new window also shows each release's commits. Switched off, none of this exists.

## Versions

Versions are written `xxx.xxx.xxx.xxx`: major (000 during development), minor (features), patch (fixes and polish) and build (the number of commits on the branch up to and including the release commit). Players see them as `v0.24.1 · build 145`.

To release:
1. Add an entry at the top of `VERSION_LOG` in `js/versions.js` (version, date, title, player-facing notes, commits, shots). `VERSION` follows the newest entry.
2. Put its screenshots in `versions/` (`<shot>.jpg`, about 720 px wide); players see them in What's new.
3. Commit, then build the release zip with `git archive --format=zip --prefix=hollow-creek/ -o hollow-creek-<version>.zip HEAD`.

## Audio

The files in `audio/` are generated by `dev/audiogen/` and listed for the game in `js/data/audiolist.js`:

- `synth.js`: the sound-effect recipes and ambience loops; `music.js`: the composer (piano, strings, bass, pads, percussion, reverb) and the track list; `gen.html` runs them; `build.js` renders them in a headless Chromium (Playwright) and encodes them with ffmpeg.
- `node dev/audiogen/build.js` rebuilds everything, `node dev/audiogen/build.js sfx|loops|music` one kind, `node dev/audiogen/build.js sfx glass` one sound. Each run also rewrites `js/data/audiolist.js` from the files actually present, so recordings added by hand (extra variations too) are picked up.
- To replace a sound with a recording, save it over the generated file of the same name; don't rebuild that kind afterwards, or the recording is overwritten.

Served over http(s), the game decodes the files into Web Audio (positioned, pitch-varied, reverb). Opened straight from disk (file://), browsers do not let a page read files that way, so plain audio elements play them, without panning.
